# MERN Stack with MySQL

This repository is a starter template for developing applications using the MERN stack (MongoDB, Express, React, Node.js) with MySQL as the database. It includes a basic setup to get you started with building full-stack applications.

## Features

- **MySQL**: Relational database for structured data storage and application data.
- **Express**: Web framework for building RESTful APIs.
- **React**: Frontend library for building user interfaces.
- **Node.js**: JavaScript runtime for server-side development.
